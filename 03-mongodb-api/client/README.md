# MongoDB + API Client (React + Vite)

Frontend application for the reusable MERN MongoDB + API Boilerplate.

## Features

- **React + Vite** setup running on port `5175`
- **Axios Service**: Centralized API instance (`VITE_API_URL=http://localhost:5003/api`)
- **Full CRUD UI**: Create, list, edit, toggle active status, and delete items
- **State Management**: Clean handling of loading states, empty states, and error alerts

## Setup & Running

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
